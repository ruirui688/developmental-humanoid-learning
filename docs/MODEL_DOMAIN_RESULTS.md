# C1 开发诊断：模型有效域、端点速度与多步位置

> 2026-10-11；仅分析已归档的 E1 v1/v2 **开发 seed 0/1/2**。不读取学习留出，不新增物理交互，不以离线回放宣称新闭环成功。

## 1. 校准没有覆盖闭环访问的状态和动作

v2 校准的肩关节位置变化只有约 0.004–0.005 rad，而学习后 MPC 实际到达约 0.075 rad 的变化。三个开发 seed 的 **194/200 个控制起点（97%）**落在校准位置最小/最大范围之外。独立 ±0.25 N·m 预测 trial 仍处于该范围附近；它的改善不能保证完整控制域可信。

以 seed 0 为例，位置相对 qref 的校准范围为 `[-0.004552, 0.00002354] rad`，闭环访问至 `-0.075207 rad`。控制还在 52–55/200 步使用绝对请求 0.375 N·m，校准没有这个剂量。

这不是失配的唯一原因：最终冻结模型在校准自身的 0.5 N·m 样本上也出现退化，约比名义端点速度预测差 70%。校准 300 步中 200 步为零命令、正负请求各 50 步；控制 200 步都是负请求。动作切换次数为校准 40/300、控制 33–35/200，不能把问题概括成单纯“控制切换更多”。

上述范围是校准数据的轴对齐包络，不能当作安全动作集合或已识别的接触模式。

## 2. 一步速度退化与多步控制收益可以同时成立

独立工具从冻结参数重建原生状态预测，分别评价 1/2/5/15 步，并与名义模型和恒速度持久性比较。每个多步窗口只在起点使用真实 q/v，之后完全自由递推，输入为记录的请求序列；不将未来真实状态喂回模型。

| v2 seed 0 的学习后 MPC 轨迹 | 名义模型 | 学习模型 | 恒速度持久性 |
|---|---:|---:|---:|
| 一步末端速度 RMSE / rad/s | 0.018119 | 0.025674 | 0.016563 |
| 一步位置 RMSE / rad | 0.000256 | 0.000500 | 0.000199 |
| 15 步末端速度 RMSE / rad/s | 0.142815 | 0.027174 | 0.037590 |
| 15 步位置 RMSE / rad | 0.023047 | 0.006345 | 0.007314 |

名义模型在多步时域持续积累速度误差，学习模型虽然一步较差，15 步却更好。三个开发 seed 的结果一致。零力矩静止轨迹上，学习模型的偏置仍使各时域预测变差，完整数据与分母均保留。

该完整200步轨迹的1/2/5/15步窗口分母依次为200/199/196/186；窗口重叠，不作为独立样本。

多步条件输入包含日志中的未来闭环请求，只能用于离线预测诊断；真实在线 MPC 不能提前知道反馈控制器未来会选择什么。这些重叠窗口也不是额外独立 seed。

## 3. 位置积分近似与最小修订候选

现模型使用 `q_next = q + 0.02*v_next`，v_next 是控制端点速度。真实 20 ms 位置变化取决于整个子步速度历程；即使端点速度预测准确，这种积分也可能有误差。

用真实原生当前/下一步速度计算的积分近似误差（oracle 诊断）显示，梯形积分能减少一步位置近似误差，但没有数学上界性质，也不能据此保证新控制收益。开发回放中的候选全部公开：

- 同参数梯形积分使闭环一步位置误差减少约 47%，15 步改善约 3%，50 步略差；没有新增拟合。
- 单独五特征平均速度头使闭环一步位置误差减少约 57%、15 步改善约 7%，但固定输入 trial 的位置误差增加约 34%；端点速度退化仍保留。
- 增加前一命令使闭环端点速度误差改善约 14%，却使固定输入端点速度误差增至约五倍。当前保留为负候选，不默认采用。

下一物理实验应先固定参数比较积分方式，再单独检验校准覆盖，避免同时改结构、探索、控制器与目标后无法归因。候选的观测回放没有执行它自己的动作，不能替代正式冻结闭环评估。

## 4. 成本与下一项执行

只读多步分析两轮各 28,116 个重叠窗口，数值与解压后的窗口记录完全相同。第二轮测得 wall 8.751925 s、CPU 8.6875 s，范围为主函数入口至验证、分析、窗口写入/哈希，不含 import 与最后 JSON 写入。首轮时间未测量，保持 unknown。两轮均无拟合。
