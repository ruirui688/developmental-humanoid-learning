# 项目优势与技术路线

> 更新：2026-10-10。本文分别保留二维 DHP-PPO、历史 PBHC/G1 工程和地面发育证据；下一阶段执行以 [项目推进路线](DEVELOPMENT_ROADMAP.md) 为准。新增 CPU 固定模型控制与门控已完成无训练验证，在线更新净收益尚未验证。当前只使用 CPU，不训练。

## 1. 项目定位

**Developmental Humanoid Learning** 研究类人发育式人形机器人运动学习：机器人不是针对每个复杂动作从随机策略开始海量试错，而是先认识自身身体、形成低维运动基元和安全平衡能力，再持续组合和迁移已有技能。

长期研究问题是：

> Can a humanoid robot learn to walk with fewer trials, fewer catastrophic falls, and less dependence on massive simulation?

当前仓库包含二维概念验证、PBHC + Isaac Gym G1 工程基础设施及单 seed 地面发育开发记录，还没有真机学习结果。历史 G1 GPU 证据来自另一台机器，本轮 CPU 未复现。

后续算法优先验证少量交互下的自监督身体辨识、局部控制和技能积累，PPO 保留为基线。先区分初始控制能力、在线身体校准与任务技能获得，再检验发育机制是否减少交互与风险。

## 2. 与常见训练范式的区别

### 常见单任务路线

```text
Task → Reward → Massive Trial-and-Error → Policy → Sim2Real
```

### 本项目路线

```text
Safe Body Exploration
        ↓
Body Schema / Forward Model
        ↓
Balance and Contact Knowledge
        ↓
Human-inspired Motor Primitive
        ↓
Supported Skill Acquisition
        ↓
Independent and Continual Learning
```

区别不在于是否使用神经网络或强化学习，而在于复杂技能是否建立在已经形成的身体知识和运动能力之上。

## 3. 核心优势

### 3.1 以严重失败成本为核心指标

真实机器人中的跌倒不是免费的负奖励。本项目除成功率和动作误差外，优先统计：

- Environment / real-world interactions；
- Number of catastrophic falls；
- Human intervention and reset；
- Energy and hardware stress；
- Skill transfer efficiency。

当前二维实验已经把训练期严重跌倒和最终测试跌倒纳入标准输出。现有 G1 地面轨也记录非足冲击、逐关节力矩余量、辅助力/冲量/机械功和 held-out evaluation 预算；阈值开发与失败分支在实验日志中公开。

### 3.2 从低风险到高风险的课程

课程按照“强支撑 → 弱支撑 → 无支撑”推进：

```text
Body Babbling → Balance → Weight Transfer → Supported Walk → Independent Walk
```

这不是机械复刻婴儿姿势，而是提取发育原则：先简单后复杂、先多支撑后少支撑、先安全后自主。

### 3.3 显式 Body Schema

策略编码器不仅服务于当前奖励，还通过前向模型学习：

$$
(s_t,a_t)\rightarrow\hat s_{t+1}.
$$

它为未来的系统辨识、风险预测、模型式 rollout 和身体变化适应提供统一接口。

### 3.4 可审计的人体运动先验

二维 DHP-PPO 的先验由交替步态相位和前庭式髋部反馈构成，其形式、样本数量和损失权重均公开记录。现有 G1 纯发育轨不加载动作文件、教师策略或预训练任务 checkpoint；共享机器人资产与底层 PD 仍是须披露的初始条件。人体先验轨可在后续实验中逐项考虑：

- Human motion capture；
- OpenSim inverse dynamics；
- Muscle synergy / NMF；
- Dynamical Movement Primitives；
- Teacher policy demonstrations。

### 3.5 同一策略的技能连续积累

五个发育阶段复用同一条件策略而非独立训练五个模型。阶段条件进入观测，使策略能够区分目标速度、步态幅度和外部支撑，并降低阶段间相互覆盖。

### 3.6 结论可证伪、结果可复现

代码固定训练预算、未见随机种子、成功阈值和最终无支撑评估条件；逐种子 CSV、统计量、图表和视频与源码一同公开。不利的关节 RMSE 结果也被保留并解释。

## 4. 当前证据

二维概念验证在 5 个未参与调参的训练种子上：

- DHP-PPO：5/5 个策略成功，150/150 个无支撑测试回合成功；
- 直接 PPO：0/5 个策略成功，0/150 个测试回合成功；
- 训练期严重跌倒由 1402.8 降至 63.0，减少 95.51%；
- 两组环境交互均为每种子 76,800 次；
- DHP-PPO 额外使用每种子 8,192 个先验监督样本。

因此当前证据支持的是“完整组合方案在理想二维代理中可行”，尚不能识别单个组件的因果贡献。

其他证据应分别解读：

| 证据轨 | 已有结果 | 结论边界 |
|---|---|---|
| PBHC/G1 工程轨 | 上游版本与资产校验，23 维关节/action、24 个刚体映射，执行器/接触/reset 审计，冻结近站立评估与录像 | 可以复用软件底座；近站立初态不能证明从地面获得技能 |
| G1 地面发育轨 | 随机初始化和四种地面初态；身体模型阶段、翻身/支撑门通过；辅助起身前沿推进至 0.29 m，0.32 m 形成平台 | 单 seed 方法开发；尚未通过持续起身和独立站立验收，也没有 Direct/Fixed/Adaptive 多 seed 优势 |
| CPU 固定模型原型 | 双关节固定模型规划、权限约束、门控状态机与无训练日志 | 验证组件运行；没有模型学习、样本效率或真实安全结论 |
| 真机轨 | 安全边界与系统设计 | 尚未开始，不能提出 Sim2Real 成功 |

G1 较强辅助及局部起身链 v1/v2 的退化分支均保留，不能把更像生物的设计当作有效性证据。来源见 [PBHC 接入记录](PBHC_INTEGRATION.md)、[G1 方法](DEVELOPMENTAL_G1_METHOD.md)和[实验日志](EXPERIMENT_LOG.md)；CPU 新增结果见 [CPU 无训练验证](CPU_VALIDATION.md)。历史 G1 记录不是本轮运行结果。

## 5. 下一步验证矩阵

### 5.1 当前优先的在线学习验证

当前先在独立低维物理任务中完成固定模型控制、权限与门控的无训练检查，不运行 PPO、监督拟合或递推辨识。后续用户明确要求学习时，再比较经典控制、简单在线辨识、冻结身体模型与在线更新模型，检验未知载荷、执行器增益或延迟下的闭环收益；随后比较成熟与探索机制。预测误差降低只能作为身体模型指标，不能单独证明技能获得。

G1 扩展复用现有 PBHC/Isaac Gym 资产、canonical 映射、原生观测接口、风险日志和冻结评估工具；这些接口与记录可先在 CPU 上审计。兼容 GPU 可用且执行范围允许时，再验证新局部控制组件与共同任务比较。Isaac Lab 是可选迁移，不是重做已有资产的前置要求。当前二维速度代理和 CPU 关节夹具都不能替代 G1 接触实验；更完整的阶段验收与近期待办见 [项目推进路线](DEVELOPMENT_ROADMAP.md)。

### 5.2 原有二维方案的因子消融

至少执行以下开关组合：

| Curriculum | Body Schema | Human Prior | 目的 |
|---:|---:|---:|---|
| 0 | 0 | 0 | 直接 PPO 基线 |
| 1 | 0 | 0 | 课程独立贡献 |
| 0 | 1 | 0 | Body Schema 独立贡献 |
| 0 | 0 | 1 | 人体先验独立贡献 |
| 1 | 1 | 0 | 身体表征与课程交互 |
| 1 | 0 | 1 | 先验与课程交互 |
| 0 | 1 | 1 | 先验与表征交互 |
| 1 | 1 | 1 | 完整 DHP-PPO |

正式研究可增加独立训练种子，并使用留出的环境参数组合进行评估；具体规模按预先确定的统计计划与资源制定。完整二维消融不作为在线身体模型原型的前置条件。

### 5.3 信息预算匹配

在需要演示的比较中给基线提供等量、相同来源的数据，并分别报告真实/仿真交互、监督样本、教师调用与计算预算。不同信息来源不能简单折算为等价环境步数。在线建模比较共享相同初始化数据，记录校准、探索、失败、适应和评估成本。

### 5.4 真实接触动力学

已有 PBHC/Isaac Gym G1 刚体接触任务；新在线模型路线优先复用它，或按需求迁移 MuJoCo / Isaac Lab，并保持资产与动作定义可追踪。新增控制组件仍须验证：

- 取消直接速度代理；
- 使用足—地摩擦、冲量与接触切换；
- 加入关节力矩、延迟、噪声和饱和；
- 评估推扰恢复和地形泛化。

### 5.5 真机安全验证

真机初期仅允许吊架或外部支撑下的 Body Babbling、平衡和单步实验。正式记录真实交互、人工复位、能耗、冲击、温度和力矩饱和。

## 6. 项目价值

如果后续消融、共同预算多 seed 的 G1 对比和真机实验继续支持该路线，项目价值不只是得到一个新的 Walking Policy，而是建立一套以技能积累、身体认知和失败前安全信号为中心的人形机器人学习范式。当前候选优先检验少量交互的在线建模与控制，已有 PPO 发育轨作为历史证据和比较基础保留。
