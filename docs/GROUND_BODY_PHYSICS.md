# CPU 地面身体探索：无训练物理底座

> 2026-10-10；这是环境与采集验收，不是身体模型或运动技能学习结果。

火柴人的原初目标是模拟小孩通过感觉运动探索逐步获得能力。为避免旧代理环境中的步态答案影响主轨，新增独立 `src/developmental_physics/`，保留旧二维环境、教师、实验数据和视频。

## 1. 本阶段实现的内容

自建简化三维身体具有自由基座，双侧肩、肘、髋、膝共 8 个力矩执行器；质量合计 7.26 kg。MuJoCo 在 CPU 上求解重力、惯性、自碰撞、关节限位、地面摩擦和接触。没有参考步态、相位时钟、目标前进速度、任务奖励或预训练策略。该身体的比例、质量、关节轴和足部结构是工程简化，不能称为真实婴儿或 G1 生物力学模型。

从仰卧、俯卧、左侧卧和右侧卧开始。采用近中立的对称微屈关节和 seed 决定的小扰动；仅将最低碰撞体放在地面上方 5 mm，没有不计账的被动稳定步骤。自由基座可翻转，但这不代表已具备主动翻身能力。

采集比较同起点的零力矩和独立关节平滑随机探索。每关节均匀采样经固定一阶滤波，系数 0.9；不设置左右反相、屈膝周期或前进偏置。目前探索器不利用反馈来选动作，只记录感觉后果，随机数状态和滤波命令变化不属于参数学习。

每个根 seed 通过 `SeedSequence.spawn(2)` 分配独立的初态与探索随机流，派生 seed 逐次保存；两种动作组共享完全相同的初态。

## 2. 初始条件与信息边界

| 内容 | 当前定义 |
|---|---|
| 仿真 | MuJoCo 3.15.0，CPU，物理步长 2 ms；每控制步 10 个物理子步，即 50 Hz |
| 共享身体信息 | 自建 MJCF、固定质量/惯量/阻尼、关节限位与接触参数 |
| 初始任务能力 | 无站立/步态控制器；有重力、摩擦、身体形态产生的被动行为，须与零力矩对照 |
| 控制观测 | 关节位置/速度，躯干陀螺仪/加速度计，执行器力矩、上一控制命令 |
| 测量假设 | 理想无噪声、无延迟传感器；精确力矩反馈，是需披露的初始条件 |
| 特权日志 | 世界位置/姿态、完整状态、COM、接触数量/法向力、动能及几何快照；不输入探索器 |
| 动作约束 | 力矩绝对值不超过 0.5 N·m；距限位 0.03 rad 内屏蔽继续向外的力矩，每子步重查 |
| 停止 | 关节速度超过 20 rad/s、关节超限 0.08 rad、动能超过 50 J、非有限状态或求解器警告时锁存停止 |

停止清零后续指令，不冻结或剪裁身体状态，也不自动复位。零指令不是已证明的安全恢复控制器。本实现是仿真停止监测，不替代独立硬件安全系统；上述上限是开发配置，不是人类或真实机器人的安全认证。

传感器和接触诊断在真实积分终点重新计算，日志分别记录请求、接受和各物理子步实际发送的力矩。所有物理子步、被动稳定过程和终止前的部分控制步计入预算。

## 3. 依赖隔离与复现

官方版本、上游 commit、许可与已核对的 Windows wheel SHA256 见 [来源清单](sources/mujoco_cpu_3.15.0.json)。保留 wheel 附带第三方许可证；本轮不采用外部身体资产、演示或检查点。

在仓库根目录运行，隔离环境保存在 Git 忽略的 `external/`：

```powershell
python -m venv external/cpu_physics_env
external/cpu_physics_env/Scripts/python.exe -m pip install --index-url https://pypi.org/simple --only-binary=:all: mujoco==3.15.0 pytest==8.4.2
$env:PYTHONPATH = "src"
external/cpu_physics_env/Scripts/python.exe -m pytest -q tests/test_ground_body_physics.py tests/test_physics_collection.py
external/cpu_physics_env/Scripts/python.exe -m developmental_physics.collect --output results/cpu_validation/ground_body_local --seeds 0 1 2 --steps 250
```

输出目录必须未存在，避免覆盖已有数据。归档包含逐控制步轨迹、原生观测与特权字段分离、逐次指标、几何快照、配置、源代码提交/dirty 状态、源码/资产 SHA256、精确依赖版本和校验清单。模型、策略和门控参数更新均为 0，教师调用和外部演示均为 0。

检查点采用临时文件原子替换；Windows 短暂权限/文件占用最多重试 10 次，累计等待不超过 2.25 s。持续失败仍报错，旧检查点与临时文件保留；不得把状态为 `running`/`failed` 或数量不足的矩阵记成完成。

MuJoCo 为可选依赖，主包入口不导入它。原有轻量测试可在未安装 MuJoCo 时运行，物理测试明确 skip；另在隔离环境实际运行这些测试。可用 `pip install '.[physics]'` 安装可选后端，但当前使用隔离环境避免改动旧二维环境。

## 4. 验收与证据边界

测试检验四躺姿无初始深穿透、空中零力矩的重力下落、无重力时不凭时间产生运动、落地接触产生力、单关节脉冲产生响应、空中总水平动量与质心的数值守恒/步长收敛、非法动作不推进状态、力矩约束、停止锁存、seed 重现和参数指纹不变。

身体比例的第一版存在前臂/大腿初始重叠，验收发现后扩大肩部间距，保留自碰撞。有限步长下内部关节脉冲有小量积分误差，测试同时要求误差受限与步长减半后下降，不能把数值漂移解释成主动推进。

本阶段不做 PPO、监督拟合或系统辨识，不启用能力晋级。得到接触、关节变化或根部位移，只能说明物理响应和采集可运行；不能证明身体认识、翻身、起身或行走已学会。

下一步先用冻结轨迹检查探索是否足以激励各关节、数据时序与接触模式是否可辨识，并确定后续身体预测协议；当前不拟合预测器。允许学习后，再比较相同初始化、相同总交互的冻结/在线身体模型及其闭环收益。
