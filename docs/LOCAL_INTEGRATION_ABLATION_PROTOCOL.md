# C2-A：同参数位置积分的开发消融

> 2026-10-11；在正式物理运行前冻结。仅 development seed 0/1/2，supine / joint 0；不执行新最终留出。

## 1. 单一改动与研究问题

C1 显示端点速度模型的一步误差与多步位置/控制误差不同。此批保持 E1 v2 的身体、校准、五特征 RLS、MPC、目标与权限，只改变位置积分；不同时修改剂量、动作时序、模型结构或控制权重。

| 冻结模型 | endpoint Euler | trapezoid |
|---|---|---|
| nominal：同一公开初始参数 | q′=q+dt·v′ | q′=q+dt·(v+v′)/2 |
| learned：同一校准最终参数 | q′=q+dt·v′ | q′=q+dt·(v+v′)/2 |

v′由相同五特征模型产生，dt=.02 s。两种积分共用同一theta、P、qref、更新次数与参数指纹；积分规则另存指纹。共同单步输入上的v′必须精确相同，不能把积分改动称为端点速度学习。多步递推的位置差异会影响后续v′，须完整报告。

新的独立适配器和运行器放在 `src/developmental_physics/local_integration.py`、`local_ablation.py`。旧 `local_model.py`、`local_learning.py` 和既有 E1 结果保持原字节。

## 2. 固定身体知识、动作与控制

模型仅使用当前原生encoder q/v、当前已知请求力矩；下一encoder v只作为校准标签。接触、实际未来力矩、qpos/qvel和仿真参数只作诊断，不进入模型或控制器。限位、方向选择、目标与基础安全系统均为共享先验，须披露。

每个 trial 从原 E1 派生 reset seed 重置，执行100步零请求前缀，真实计账；参考和方向由前缀末原生encoder与公开限位建立，必须精确配对。校准300步的10个30步block幅度为 `[.125,.25,.5,.125,.25,.5,.125,.25,.5,.125]`，各block时序沿用5步正向、10步零、5步反向、10步零，每个完整校准转移进行一次RLS更新。无额外warm start。

共同独立预测trial为100步，沿用v2固定请求（每20步7步方向×.25、3步零、7步反向×.25、3步零）。两个模型与两种积分在完全相同的输入轨迹上评估，全部冻结；没有独立采集四份预测轨迹。

四个独立MPC trial各200步，前100步当前目标为qref+direction×.04，后100为qref+direction×.08。保持H15、9个候选和全部原权重/范围/回退/决胜规则；控制只知道当前目标，无切换预告。请求上限均为.5 N·m，其他关节请求为0，独立环境保护保持原值。每个trial完整记录数学预测次数、规划墙钟和真实子步。

## 3. 预算与失败

每seed：校准400 + 预测200 + 四MPC各300 = **6 trials、1,800控制调用、18,000子步、300次RLS更新**。三seed共 **18 trials、5,400控制调用、54,000子步、900次更新**；前缀1,800调用/18,000子步，校准900/9,000，预测300/3,000，控制2,400/24,000。模拟时间108 s；策略更新、教师和演示均为0。

普通trial失败保留实际成本，按依赖阻塞或继续独立trial；中断及日志写盘故障立即结束本批、其余计划标blocked。不能补跑、删除失败或在结果后扩大预算。部分物理步的请求努力按真实执行子步×.002 s计费，未返回遥测明确缺失/下界。

## 4. 实现验收与科研采用门

实现验收：源码commit/原字节ZIP/依赖/配置/manifest完整；前缀配对；RLS独立重算、theta/P/更新数和冻结hash链；原生预测输入隔离；PD批与原E1共享环境/目标/权限；Euler校准/预测/控制锚点与历史v2 development原生物理轨迹精确复现。失败不满足科研采用门，但仍须合法计账。

独立审计报告四组完整tracking RMSE及两种因素差异、交互项；共同预测与各自闭环轨迹的1/5/15/50步位置/速度自由递推。合法窗口使用真实初始状态和记录的未来请求，不回灌未来状态；未来请求仅为离线诊断条件。控制窗口分母200/196/186/151，预测100/96/86/51；重叠窗口不作独立seed。最终模型在校准轨迹上的评分标为in-sample。

采用梯形积分的开发门预先固定：三seed的learned两组均完整且跟踪各seed不劣；原始tracking RMSE均值相对Euler至少降低5%；实际绝对力矩努力、实际平方力矩努力的三seed均值增幅分别不超过5%。不使用近似tie或挑seed。未满足则保留Euler默认，记录消融负结果；不据此修改阈值或追加积分候选。

同时报告全程及控制期接触力/动能峰、速度、限位屏蔽、饱和与穿透；这些不能因均值努力门通过而省略。一步或15步改善不能掩盖50步退化。采用门只决定开发默认，不证明风险下降、任务获得或新留出优势。
