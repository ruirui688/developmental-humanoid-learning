# CPU 发育式学习：当前持续目标

> 更新：2026-10-12。目标持续执行中；一次实验、报告或提交都不代表完成。

我们要验证：**机器人能否用自己的动作和感觉，通过少量 CPU 身体辨识，形成有用的身体模型，再依靠预测控制与能力门控逐步获得运动能力。** 当前不使用任务教师、预训练任务策略、大规模 PPO、GPU 训练或真机。先验证低维多关节机制，再决定如何扩展到站立和行走。

身体结构、关节限位、任务目标、经典 PD 控制、固定支撑和理想传感都属于初始先验，必须公开。要测量的是这些条件下**交互后新获得的能力**；预测误差下降不能直接代替控制能力提高。

**最早未验收的是 C4：双关节完整闭环控制，以及躯干可自由运动的刚体接触任务。** 固定悬挂中的预测成功不能解除这一依赖。C5 只有事件接口工程通过，科学适应实验仍待 C4；C6、C7 尚未验收。

## 初期验证的四项完成条件

1. **C4：身体模型真正帮助完整控制。** 至少两个关节，单步和多步预测、完整任务跟踪与实际努力一起报告；与相同初始化的冻结模型、调优经典控制公平比较。先通过事前控制门，再在自由躯干接触域和新留出条件复核，部分完成或停止轨迹不排名。
2. **C5：能适应未知动力学变化。** 至少两类未见变化，比较冻结模型与少量更新模型的恢复过程；报告预测、控制、交互、努力与失败。冷启动获得能力与已有能力的变化适应分别计量。
3. **C6：能力门控有公平的机制证据。** 固定成熟与能力门控使用相同最终任务、权限和完成标准；记录探索、校准、晋退级、停滞和风险。更多支撑或永久小动作带来的少失败，不能算作技能提高。
4. **C7：新留出、强基线和消融完成综合验收。** 使用未参与开发的 seed/条件，保留全部失败和实际成本，能够从配置、源码和逐 seed 记录复核；明确哪些机制成立、哪些不成立，并完成检查、提交和推送。

负结果必须公开，但一次失败或一份否定报告不能把尚缺 C4–C7 的初期科学验证标记完成。失败后只推进有证据、有限预算的新判断或修订；不放宽旧门、不补跑到成功，也不无限重复同一失败。
