# E1：局部身体辨识与冻结模型控制的 CPU 初期验证

> 2026-10-11；正式学习与评估前冻结。用户已授权少量 CPU 在线辨识，检验身体模型学习和控制收益；不开展 PPO、大规模策略训练或真机实验。
>
> 本协议验证真实刚体接触环境中的一个局部关节任务。它不代表翻身、起身、站立或行走学习，也不证明整个发育路线已经成立。

先通过 [逐关节探针协议](JOINT_PROBE_PROTOCOL.md) 的动作—感觉前置门，再执行本协议。保持 [现有物理底座](GROUND_BODY_PHYSICS.md) 的资产、baseline 接触、力矩权限、原生感觉和停止条件，不增加支撑、目标姿势教师、步态参考或预训练控制策略。递推最小二乘是本阶段明确允许的参数学习；自监督标签来自机器人自身下一控制时刻的编码器速度。

## 1. 研究问题与条件选择

主要问题是：相同的少量固定校准数据能否使局部预测优于初始冻结模型，并且在完全相同的控制目标、规划器与权限下，转化为更好的闭环跟踪？

只依据探针**开发集**选一个姿态/关节：按环境唯一 `POSES` 顺序 `supine`、`prone`、`left_side`、`right_side`，再按唯一 `JOINT_NAMES` 顺序，选择第一个在 seed 0/1/2 的 0.5 N·m 条件中全部满足脉冲末端有符号配对响应至少 1e-3 rad、且对应 trial 完整无停止/异常的组合。选择规则不看学习、控制或留出结果，也不挑响应最大的组合。保存用于选择的探针 trial ID、原始值与归档 hash。

若开发探针没有符合条件的组合，不启动 E1。若选定组合在探针留出集未通过同样响应门，记录前置失败，不改选下一个组合来追逐留出成功。身体学习条件、模型与控制配方在留出 E1 运行前冻结。

开发 seed 固定为 0/1/2，正式留出 seed 固定为 10/11/12。每个 seed 都从相同名义模型独立冷启动，在其本身的校准轨迹上允许更新；不沿 seed 传递参数，不调用其他 seed 的学成模型。这里的“留出”指没有参与任务、超参数或模型选择；不指该 seed 禁止自身校准。预测评估轨迹和控制评估轨迹不进入更新，也不以相邻时间窗口切分来制造留出样本。

## 2. 信息边界与固定时间协议

身体、惯量、阻尼、接触、执行器参数及停止阈值保持原值。学习器只读取选定关节的当前原生 `joint_position`、`joint_velocity` 和**调用前已知的请求力矩**。共享身体信息只有动作映射、公开关节上下限、控制间隔 0.02 s 和原有安全层；真实惯量、摩擦、完整世界状态及接触真值只进入特权日志。

执行器力矩端点反馈及实际子步力矩用于诊断命令屏蔽和执行差异，**不是预测输入**。主预测必须在 `env.step` 前形成，不能先读取下一时刻实际力矩、状态或隐藏参数再称为因果预测。由于限位安全层仍可改变请求，学习的是当前环境加安全执行层的局部有效响应；这不等同于唯一辨识出物理惯量或电机参数。

每个独立 trial 都重新从同 pose/seed reset，真实执行 **100 步/2 s 付费零力矩前缀**；不重用已稳定的物理状态、不扣掉被动冲击。前缀末端的选定关节 encoder 定义参考 `q_ref`，按探针的公开限位余量规则选择固定方向 `s`，此后方向不更新。相同 seed 下各 trial 的前缀应精确复现，`q_ref` 与方向相同；否则首先判为复现失败。

物理 dt 固定 0.002 s，每控制调用最多 10 子步；每次请求只作用于选定关节，其余 7 关节请求为零。仍允许真实接触和多关节耦合；不能把该简化局部模型解释成全身身体模型。

## 3. 固定校准与 RLS 更新

每个 seed 只真实运行一份校准轨迹：前缀 100 步，加校准 **300 步/6 s**。校准由 10 个完全相同的 30 步 block 组成：

| block 内索引 | 请求力矩 |
|---|---:|
| 0–4（5 步） | `s * 0.5 N·m` |
| 5–14（10 步） | 0 |
| 15–19（5 步） | `-s * 0.5 N·m` |
| 20–29（10 步） | 0 |

双向脉冲只是固定辨识输入，不保证两方向实际力矩相同；保留安全层全部屏蔽。没有根据残差调整动作、改变 block 长度或追加校准。10 个 block 的每个真实控制转移都计入预算，包含零力矩；前缀不进行模型更新。

ARX 模型预测下一控制端点速度，特征固定为：

```text
x_k = [v_k, q_k - q_ref, u_requested,k, 1]
v_pred,k+1 = theta @ x_k
q_pred,k+1 = q_k + 0.02 * v_pred,k+1
theta_initial = [1, 0, 0.02, 0]
P_initial = 100 * I_4
lambda = 1
```

名义参数相当于忽略重力、阻尼和接触的单位惯量离散近似；它是共享且需披露的初始预测先验，不是从真实仿真参数读取的正确模型。位置使用这个简单积分近似，误差可能来自模型形式，也必须报告。

每次校准调用前保存当前原生 `q_k,v_k`、请求 `u_k` 和预测；真实执行之后用原生 `v_k+1` 作自监督标签，按标准 RLS 更新：

```text
gain = P @ x / (lambda + x.T @ P @ x)
theta_new = theta + gain * (v_next - theta @ x)
P_new = (P - outer(gain, x.T @ P)) / lambda
```

实现为数值对称性对 `P_new` 做 `(P_new + P_new.T)/2`，不能引入未披露的参数剪裁、正则搜索或残差门控。保存初始/最终参数与协方差快照、逐次特征/标签、更新前后指纹、预测误差和实际更新数，供离线重算全部参数更新；完整无异常校准最多更新 300 次。输入/输出非有限、分母非法、参数非有限或仿真停止时保留失败记录，不忽略坏转移后继续制造完整样本。不跨 reset 创建假转移。

校准完成后保存模型与协方差 SHA256，**所有预测和闭环评估冻结参数与 P**，评估更新数为零；控制器的上一命令或当前候选选择可以变化。冻结模型组得到同样校准数据与预算，但始终使用相同初始 `theta`，参数更新为零。

## 4. 独立固定输入预测评估

每个 seed 另起一条 trial：前缀 100 步，加预测评估 **100 步/2 s**。由 5 个完全相同的 20 步 block 组成：

| block 内索引 | 请求力矩 |
|---|---:|
| 0–6（7 步） | `s * 0.25 N·m` |
| 7–9（3 步） | 0 |
| 10–16（7 步） | `-s * 0.25 N·m` |
| 17–19（3 步） | 0 |

它与校准的 5/10/5/10 节律和剂量不同；全轨迹禁止更新。学习后模型与初始冻结模型读取**同一条真实评估轨迹**，在每次调用前用当前原生状态和即将发送的请求分别作单步预测。主要指标为评估 100 个端点的选定关节速度预测 RMSE；可以从已存原生轨迹另列持久性 `v_pred=v_k`、位置预测误差、逐 block 误差、实际力矩/请求差异及限位屏蔽，不据此选择模型。

单步评估每次使用真实当前状态，不伪装成自由滚动的长时预测。本次未独立评估自由滚动预测误差；规划器内部的 15 步预测不能代替这种留出检验。

相对改进定义为 `1 - RMSE_learned / RMSE_frozen`。冻结 RMSE 为零时不能报告无限改善；该 seed 的相对门不满足，保留原始 RMSE。任何停止造成缺失端点时标记完整评估未完成，不能把已执行的容易片段当成 100 步结果。

## 5. 冻结模型闭环、PD 与零力矩对照

每个 seed 对以下四种方法分别真实 reset：

1. `frozen_mpc`：初始冻结 ARX + 相同候选预测控制；
2. `learned_mpc`：自身校准所得冻结 ARX + 相同候选预测控制；
3. `fixed_pd`：固定 `Kp=4 N·m/rad`、`Kd=0.2 N·m/(rad/s)`，请求 `Kp*(target-q)-Kd*v` 后饱和到 ±0.5 N·m；
4. `zero_torque`：全程请求零力矩，被动轨迹对照。

每个方法前缀 100 步，加闭环 **200 步/4 s**。控制目标预先给定，并披露为任务信息：控制索引 0–99 为 `q_ref + s*0.04 rad`，100–199 为 `q_ref + s*0.08 rad`，目标速度为零。这不是外部运动示范；但目标幅度、PD 增益、规划权重与安全层都是已有算法/任务先验，其贡献不得称为学习所得。

两个目标都须在共享限位内侧 0.03 rad 范围内。若所选姿态/关节/seed 的某个目标不满足，标记任务不可行并保留该 seed；不剪裁目标、换方向或临时减小幅度。不把这种失败隐藏成模型失效，也不从正式指标删除。

两个 MPC 具有完全相同的候选、时域、代价、约束和动作权限：

| 项目 | 固定值 |
|---|---|
| 候选请求 | `[-0.5, -0.375, -0.25, -0.125, 0, 0.125, 0.25, 0.375, 0.5] N·m` |
| 时域 | 15 控制步，0.30 s；每个候选在预测中保持恒定，实际只执行首步，下一控制时刻重算 |
| 状态递推 | 第 3 节同一 ARX 和位置积分；仅使用冻结模型，不查询真实仿真器的候选结果 |
| 目标时序 | 每次规划的 15 步均使用当前目标；到真实控制索引 100 时才切换目标，不提前输入未来目标切换 |
| 代价 | 每步位置误差平方权重 1、速度平方权重 0.002、请求力矩平方权重 0.00002、相邻请求变化平方权重 0.00002；对 15 步求和 |
| 变化代价 | 预测首步相对当前真实上一请求，后续恒定候选的变化为零；前缀末上一请求为零 |
| 预测位置域 | `[q_ref-0.15, q_ref+0.15]` 与 `[lower-0.03, upper+0.03]` 的交集；允许公开软限位外 0.03 rad 的预测余量 |
| 预测速度域 | 每个预测端点 `abs(v_pred) <= 1.5 rad/s` |
| 可行性 | 任何一步越预测域或非有限即候选不可行；禁止通过裁剪预测状态掩盖越界 |
| 并列与回退 | 同代价先取较小绝对力矩，再取数值较小者；无可行候选时请求零并记录回退原因/次数 |

预测域只是该规划器的局部约束，不替换既有物理环境的停止阈值。零回退也不是已经验证的安全恢复；报告真实状态越局部域、限位屏蔽、动能、接触冲击和停止，不能只给模型预测的安全性。固定 PD 与零对照执行同一目标/预算/实际权限，且不读取特权观测。

主要跟踪指标为 200 个控制端点 `q_next - target_current` 的 RMSE，另报告两目标窗口的 RMSE、速度、绝对误差积分、目标末端误差、力矩积分、请求变化、限位屏蔽、回退、停止及完整特权风险。公开学习前的 `frozen_mpc`、PD 和零对照表现，不把一个已经容易被 PD 解决的任务描述成全新复杂技能获得。

## 6. 预定初期验收与结论范围

独立数据/实现检查均须通过：源码与协议冻结、信息边界、predict-before-step、时序和完整计账可重算；全部请求合法；模型只在校准更新，评估参数/P hash 不变；环境参数、接触和安全权限始终不变。

支持“E1 的局部身体模型学习转化为控制收益”需要同时满足：

- 探针前置门通过，且选定姿态/关节满足本协议事先固定的开发与留出规则；
- 三个留出 seed 的单步速度预测 RMSE 相对于初始冻结模型**各自至少降低 20%**，完整评估无缺失；
- 三个留出 seed 的 `learned_mpc` 跟踪 RMSE **逐 seed 都低于 `frozen_mpc`**，三个 seed 的原始 RMSE 均值相对降低至少 20%；不是平均各 seed 百分比来代替均值比；
- 三个留出 seed 的学习/预测/`learned_mpc` 运行无停止、异常、非法请求或非有限状态；固定对照的停止与缺失仍完整报告，不能用截断后不完整 RMSE 声称优势。主跟踪比较要求两 MPC 都有完整 200 步。

PD 是否更强必须报告，但本门不要求新模型控制击败 PD：若学习组只优于差的初始冻结模型而不如 PD，结论限定为“在相同规划器中的局部模型贡献”，不宣称优于经典控制。若预测改善而闭环不改善，E1 整体门不通过；若只改善变化后适应则不能称冷启动技能获得，本协议目前不包含载荷/延迟变化适应实验。

门槛是本次开发验证约定，不是统计显著性、安全认证或广泛泛化标准。只有 3 个正式 seed，报告全部逐 seed 数值及正负结果，不将时间点、共享对照或多个模型预测重复计作独立样本。

若 E1 未通过，保留并提交负结果，先检查激励不足、ARX 局部有效性、请求与实际力矩差异、预测时域和候选离散化；不能在留出集反复更换校准脉冲、权重或目标直到成功。任何新版本在开发集修改、单独计账、重新冻结，再使用新的留出条件。不要把较小预测残差直接当作能力门，也不因失败提高权限或删除不利 seed。

## 7. 公平预算、归档与执行顺序

每个 seed 的真实仿真成本如下，无提前停止/异常时：

| 真实运行 | trial 数 | 控制调用 | 物理子步 |
|---|---:|---:|---:|
| 共享校准，100 前缀 + 300 更新时段 | 1 | 400 | 4,000 |
| 共享固定输入预测，100 前缀 + 100 评估 | 1 | 200 | 2,000 |
| 四方法独立闭环，分别 100 前缀 + 200 控制 | 4 | 1,200 | 12,000 |
| 每 seed 合计 | 6 | 1,800 | 18,000 |
| 开发 3 seed | 18 | 5,400 | 54,000 |
| 留出 3 seed | 18 | 5,400 | 54,000 |
| 两 split 合计 | 36 | 10,800 | 108,000 |

两 split 计划仿真时间 216 s。每个方法得到同一份 400 控制步的校准信息；冻结、PD 与零组可以不使用这些数据，但信息/冷启动预算仍披露。真实校准仅运行一次，不虚增执行次数；独立部署每方法若都要重新采集，应另列其对应冷启动预算。共享预测轨迹也是一次真实运行，多个预测器读取它不增加物理交互，亦不增加独立轨迹样本数。

逐方法报告 400 校准信息步 + 自身 300 闭环执行步；另外单列公共预测评估 200 步与已有探针选择成本。若沿用探针采集确定局部任务，其开发和留出预算全部在项目总账中保留，不能只报 E1 的 10,800 步就声称从无知识快速获得能力。参数更新、规划候选模拟量、CPU 计算与真实物理步分别计量；规划器没有外部仿真器查询。

所有失败、不可行目标、reset、停止前部分子步、测试/smoke 与正式运行分别计账；不把“未执行”写成合法零动作或完整控制步。归档保存：选定条件与来源、配置/seed、每次调用前预测和调用后原生标签、请求/实际力矩、全部 RLS 更新及冻结模型、逐方法指标、源代码提交/dirty 状态、依赖/CPU、墙钟、协议与源码原字节快照、hash 清单及独立重算结果。

先完成 RLS 数值与已知系统测试、信息隔离、predict-before-step、模型冻结、目标不可行、MPC 可行性/回退和故障预算测试；提交实现与协议后从干净提交运行开发。若开发产生配方修改，公开修改与额外交互，再冻结后运行留出；不得让留出结果参与调参。最终保存通过或未通过的实际结论及其范围，CPU 局部接触学习结果与历史 G1/GPU 轨分开报告。
