# Z1：2ms身体辨识与多时距预测开发结果

首次 Z1 从 clean `7d323dcc4b8c303c8d76430763a09b36dbb8130a` 执行，三个 seed 的校准和独立预测轨迹全部完整，零研究停止、异常和 failure。冻结的独立预测全门通过：H10v（20ms）三 seed 原 RMSE 均值的肩/肘改善分别为 **99.2325% / 98.8250%**，H150q（300ms）分别为 **97.0043% / 97.6122%**；每 seed 两轴均严格改善，H20/H50 q/v 及 H150v 均不劣。

这是固定悬挂支撑、理想原生感觉和公共经典 PD 下的局部身体模型预测开发结果。后续 [Z2 首次控制](FAST_FEEDBACK_PAIR_CONTROL_RESULTS.md)已完整完成，但同 MPC 贡献仅 7.55%，未达到原 20% 门，自身长时肩预测退化。Z1 独立预测通过不能据此宣布完整自由 root 接触 C4、C5 科学适应、成熟机制、站立或真机成功。

## 冻结条件与验收状态

[学习协议](FAST_FEEDBACK_LEARNING_PROTOCOL.md)在新学习数据产生前冻结；Z0 工程资格与边界见[工程结果](FAST_FEEDBACK_ENGINEERING_RESULTS.md)。模型使用 2ms 原生转移，实际 PD 每 2ms 重算；后续 Z2 的残差 MPC 每 20ms 决策。本轮 Z1 无 MPC。

两个模型共享新初始化 `Theta_2ms = E + .1*(Theta_generic_20ms-E)`，保留本轴速度 identity，并将公开 generic 请求系数从 `.02` 缩为 `.002`。这是假定增量按时间一阶缩放的先验，不是实测动力学。coupled_hinge9、公开 KnownAngleGuard、hinge `.25`、P100I、lambda1 和原子两 head RLS 保持；更多高度相关的微步更新改变先验相对权重，不能称为十倍独立样本。每 seed 18 个学习系数，只消费当前两轴 q/v 和已知最终请求，不读取未来实际力矩、接触、root 姿态或隐藏动力学。

固定 upright torso、原八轴资产/电机、最终每轴 `.5 Nm`、其余六轴请求零，以及公共 PD64/Kd4 都属于初始条件。停止仍为 active 完整端点 `abs(q-qref)>=.12 rad` 或 `abs(v)>=1 rad/s`，不放宽；prefix 只走基础保护。
