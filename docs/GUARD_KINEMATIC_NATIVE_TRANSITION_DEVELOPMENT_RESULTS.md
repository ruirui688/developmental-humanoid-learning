## 干预与边界

R 从冻结 Q22（source `20fa0321c84eb766eeafb9f8d906f554bca60622`）出发；每一步完整调用原 Q 一次，再仅覆盖两受控位置：

```text
next_Q22 = prior_K22(x, previous_v, request) + phi50_Q(...) @ saved_W_Q
next_R22 = copy(next_Q22)
next_R22[0:2] = x[0:2] + .01 * (x[8:10] + next_Q22[8:10])
previous_v_next = old_x[8:10]
```

DT=.02，.01=DT/2；q 状态已经是 q−qref。其余 20 个当前候选输出原样保留，两 Q 位置头仍计算、计费后丢弃。完整 22 维继续自身递归，previous_v 取连续旧端点，未来已知请求仅为离线 oracle。没有位置混合、速度校正、拟合、扫描、新数据、P 记忆或 N 尺度。

梯形公式属于公开运动学先验，端点速度平均不保证等于区间真实积分；不能把该替换称为获得了身体动力学。Q/K/D 仅恢复保存参数，各 seed 保存的恢复前后指纹相等。原 C 中隐藏量和原生端点只按冻结输入白名单使用；本轮无物理、完整闭环控制、新留出、适应、成熟或真机实验。
