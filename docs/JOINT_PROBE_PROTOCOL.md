# 逐关节小脉冲：身体学习前的动作—感觉验收协议

> 2026-10-11；正式采集前冻结。只使用 CPU，保持原身体、baseline 接触和 0.5 N·m 力矩上限。
>
> 本轮用户已允许少量 CPU 在线辨识，以检验身体模型学习及闭环控制收益。本协议只规定其前置探针：采集过程中不拟合、更新模型或优化策略；通过探针不等于完成初期项目学习验证。

此前固定随机探索的平均实际力矩很小，2 s 零力矩前缀之后的主动关节差异仍弱，膝关节限位屏蔽没有消失。本次将同时改变多个关节的随机命令换成固定单关节脉冲，检验当前权限能否产生可重复的原生感觉响应。保持接触参数原值，不采用已经发现穿透代价的柔顺变体。历史结论见 [接触/前缀结果](GROUND_CONTACT_PREFIX_RESULTS.md)，信息边界见 [物理底座](GROUND_BODY_PHYSICS.md)。

## 1. 前置验收与初期项目验收分开

本轮初期项目验证至少需要两个阶段：

1. **动作—感觉前置验收**：探针的时序、实际力矩、限位屏蔽、原生感觉和交互账本可信，至少一个局部关节响应能在开发与留出 seed 中复现。本协议定义这一阶段。
2. **身体学习与闭环验收**：另行冻结学习协议，对比相同初始模型的冻结/在线组，以及适合任务的简单预测或经典控制；在未见完整轨迹上检验预测改善，再检验其是否转化为同预算、同权限下的局部控制收益。计入校准、探索、更新时交互和全部评估成本，公开无收益的 seed。只有完成这一阶段才能判断本轮身体学习候选是否得到初步支持。

一个关节动了、脉冲后误差下降、通过采集检查或某组不触发停止，都不能代替第二阶段。探针不包含翻身、起身、站立、行走目标或能力晋级；通过本协议不支持这些技能已经获得，也不支持真机结论。

## 2. 冻结条件与矩阵

| 项目 | 固定定义 |
|---|---|
| 后端与身体 | 当前 MuJoCo CPU、7.26 kg 自建身体、8 个力矩关节；资产、惯量、阻尼、摩擦、自碰撞保持原值 |
| 接触 | `baseline`，不覆盖 MJCF 的地面或身体接触参数 |
| 起点 | `supine`、`prone`、`left_side`、`right_side`；相同 pose/seed 下所有幅度、关节和零力矩组共享初态 |
| 开发 seed | 0、1、2 |
| 留出 seed | 10、11、12；正式留出采集前冻结实现与本协议，不按开发结果删改姿态、关节、幅度或时长 |
| 关节顺序 | `left_shoulder`、`left_elbow`、`right_shoulder`、`right_elbow`、`left_hip`、`left_knee`、`right_hip`、`right_knee`；使用环境唯一映射，不新增另一套动作顺序 |
| 请求幅度 | 0.125、0.25、0.5 N·m；一次仅一个关节非零，其他关节全零 |
| 前缀 | 100 控制步、2 s 全零力矩，不按“是否稳定”延长或跳过 |
| 脉冲窗口 | 随后 25 控制步、0.5 s；单关节恒定方向与幅度 |
| 恢复窗口 | 随后 75 控制步、1.5 s 全零力矩；“恢复窗口”仅指观测时段，不预设已经恢复稳定 |
| 总预算 | 每 trial 最多 200 控制步、每步 10 个 2 ms 子步，即 4 s；无隐藏稳定、状态裁剪或中途重置 |
| 安全与停止 | 既有 0.03 rad 限位外向力矩屏蔽、20 rad/s 关节速度、0.08 rad 超限余量、50 J 动能停止及非有限/求解器警告停止均不变；每子步检查，停止锁存 |
| 测量假设 | 原理想无噪声、无延迟 encoder/IMU 与精确执行器力矩反馈；共享限位属于已披露身体信息 |
| 更新与教师 | 探针阶段模型、策略、增益和门控阈值更新均为 0；教师调用、任务演示和预训练策略均为 0 |

每个 pose/seed 真实运行 **1 次共享零力矩对照 + 8 关节 × 3 幅度 = 25 trials**。开发集为 **4 × 3 × 25 = 300 trials**，留出集同配方另 **300 trials**。共享零力矩完整执行相同 2 s/0.5 s/1.5 s 三段，全程实际请求零力矩；不为每个配对复制一份仿真并伪装成独立样本。每个零力矩 trial 对应的 24 个脉冲配对显式保存同一对照 ID。

开发与留出各自只有 12 个 pose/seed 初态；同一初态下不同关节、幅度及共用零力矩配对不是独立 seed。完整留出矩阵不只是重复开发集中最有利的关节。顺序固定为 split、pose、seed、共享零力矩、关节顺序、递增幅度；不根据反馈跳过未通过条件。

## 3. 脉冲方向与命令时序

在恰好执行 100 个零力矩控制步后，从原生 `joint_position` 读取目标关节的编码器值 `q_j`，用共享关节上下限 `l_j,h_j` 比较剩余范围：

- 若 `h_j-q_j >= q_j-l_j`，方向 `s_j=+1`；
- 否则方向 `s_j=-1`。

相等时固定取正方向。角度不裁剪，方向一旦选择，在整段脉冲内不再变化；限位安全层仍每子步独立屏蔽。保存方向、前缀末端 encoder、所用上下限与方向规则版本。相同 pose/seed 的各幅度具有完全相同前缀，所以同关节方向应一致；零力矩对照的前缀也应逐行相同。

动作选择只用这一个原生 encoder 与共享限位，不读取接触、世界姿态、动能、仿真器惯量或未来状态。共享方向规则是结构化探针先验，不是学习所得；选择较大范围也不保证接触下动作安全或目标关节必然沿请求方向运动。

控制调用使用从 0 开始的索引：0–99 为 `prefix`，100–124 为 `probe`，125–199 为 `recovery`。对脉冲组，100–124 的请求向量仅第 `j` 项为 `s_j A`；其余调用全零。对共享零力矩组全部请求全零，但阶段标签和时间窗口相同。保存每次调用前后的时间、阶段、请求/接受命令、实际子步命令及原生观测；日志端点重新计算传感器，不把积分前读数当成动作后结果。

## 4. 事先规定的原生感觉指标

以同 pose/seed 的真实共享零力矩轨迹为 `Z`，对应脉冲轨迹为 `P`。只在相同已完成物理时间点配对，不填补停止或异常后缺失状态。前缀末端 `t=2.00 s` 的状态应精确相同。主要响应指标为脉冲结束 `t=2.50 s` 的目标关节有符号差异：

```text
D_j = s_j * (q_j^P(2.50) - q_j^Z(2.50))
```

正值表示相对于同起点被动对照，目标关节沿请求编码器方向变化。这里没有减去未配对的绝对角度，也不把被动滚倒导致的关节变化记为主动响应。固定解析门槛为 **`D_j >= 1e-3 rad`**，约 0.057°。这是当前理想无噪声模型中的描述性数值门，不是硬件可辨识性、安全阈值、预测精度或任务成功标准；本轮不按结果修改门槛。

全部条件同时报告以下指标，不能只保存越门的关节：

1. 目标关节在脉冲/恢复两个窗口的配对 encoder 差异 RMS、最大绝对差异、`D_j`，以及恢复末端 `t=4.00 s` 的残余差异；其他 7 关节的差异作为耦合响应另列。
2. 相同窗口内原生 `joint_velocity` 的逐关节配对差异 RMS，以及 `imu_gyro`、`imu_acceleration` 的配对向量差异 RMS；单位分别为 rad/s、rad/s、m/s²。IMU 差异只描述整体感觉后果，不解释为已识别接触或已学会控制。
3. 从脉冲开始到第一个已记录端点满足 `s_j * (q_j^P-q_j^Z) >= 1e-3 rad` 的时间；脉冲窗口未达到时标记“未达到”，不改为恢复窗口的最好时刻，也不把该端点当作真实执行器纯延迟。
4. 请求、接受和全部实际子步力矩的 RMS、绝对积分与沿请求方向的积分；目标关节非零请求被屏蔽比例，以该关节**实际执行的非零请求子步**为分母，分母为 0 时记录未定义。实际力矩与请求同时给出，不把 0.5 N·m 请求当作每个子步都执行到 0.5 N·m。
5. 每个 pose/seed/joint 的三幅度 `D_j`、实际力矩积分和限位屏蔽曲线。剂量响应为预定描述比较，不要求所有接触条件普遍单调，也不从三点拟合/选择最优幅度。

对子步接触力峰、法向力积分、最小接触距离、动能峰、停止原因及完整状态仍按旧格式做特权诊断，不输入方向选择器或未来学习模型。全程和三阶段都报告：2 s 前缀的初始落地冲击不得从“风险”图中删除。最小接触距离包含地面和自碰撞，不能单凭此值判断身体陷入地面；没有停止也不等同于安全验收。

## 5. 探针过关条件与失败处置

先独立检查数据完整性，随后检查响应门。全部条件与判定在正式采集前冻结：

- 关节映射、baseline 接触、实际参数指纹、源代码/资产/协议 hash 均与冻结配置相符；前后参数不变，参数更新与教师调用为零。
- 矩阵 300 + 300 trials 的全部预定标签和对照 ID 唯一且齐全；真实调用与部分子步可重算，方向规则、请求窗口和每子步权限检查通过。失败/停止 trial 留在矩阵与账本中，不补跑成成功 seed，不把缺失指标写成零。
- 同 pose/seed 的前缀原生观测/状态与共享零力矩精确复现；同关节跨幅度方向一致。任何这一类不一致先记为实现或复现失败，不解释成动作响应。
- 至少有一个**相同的姿态/关节**，其 0.5 N·m 条件在全部 3 个开发 seed 和全部 3 个留出 seed 的 `D_j >= 1e-3 rad`，且这些 trial 完整执行、无停止、无异常、无非有限状态。这个条件仅确认当前局部权限能提供重复的动作—感觉响应。

报告每个姿态/关节的六个逐 seed 结果和三剂量响应，记录全部通过条件，不只挑一个最好例子。其他条件的停止、反向响应或遮蔽必须同时报告；上述局部门通过不构成整个探索矩阵低风险的证明。

若未过局部响应门，保留负结果，先区分实际力矩被屏蔽、地面约束、方向选择、传感时序和权限不足；不提高力矩、不改默认接触或事后调整门槛来制造通过。若变更探针，另写版本、另计开发与采集成本，再冻结新的留出评估。通过后才将结果用于约束后续学习协议的局部任务范围；不能靠只选有利响应条件宣称全身学习能力。

## 6. 预算、归档与执行顺序

| 预算（无提前停止/异常时） | 每个 split | 两个 split 合计 |
|---|---:|---:|
| trial | 300 | 600 |
| 控制调用/完成控制步 | 60,000 | 120,000 |
| 实际物理子步 | 600,000 | 1,200,000 |
| 仿真时间 | 1,200 s | 2,400 s |
| 前缀控制步/子步 | 30,000 / 300,000 | 60,000 / 600,000 |
| 脉冲窗口控制步/子步（含共享零对照） | 7,500 / 75,000 | 15,000 / 150,000 |
| 恢复控制步/子步 | 22,500 / 225,000 | 45,000 / 450,000 |
| 有非零请求的控制调用/子步 | 7,200 / 72,000 | 14,400 / 144,000 |

统计实际执行量时分别保存调用尝试、已返回完成控制步和实际物理子步；中途异常前已积分的子步仍计费。记录每个 trial 与每个阶段的预算、原始停止/异常、完整配置、根/派生 seed、源代码提交/dirty 状态、实际依赖、CPU/GPU 状态和墙钟时间。测试、smoke、正式开发、正式留出与后续学习各自列账；本次预算加到旧四次地面采集的 38,750 控制调用 / 387,500 子步，不覆盖旧账。

后续若多个方法重用探针数据，分别说明公共数据预算与每个方法获得的数据；共享一份文件不会消除其采集成本。模型控制中的真实仿真器查询必须另外计量，不能与不执行物理步的内部模型预测混写。共享零力矩的 24 次配对引用只对应一次实际采集，不额外制造样本量。

实施顺序：

1. 先完成脉冲方向、阶段边界、单关节命令、共享对照、限位屏蔽、预算与故障保留的相关测试；提交本协议和实现，从干净提交采集。
2. 单独保存开发与留出归档，不覆盖既有结果。留出运行使用相同冻结配方；开发结果若促使修改实现/指标，先公开修改与成本，重新冻结后才运行新的留出集。
3. 归档原始 trace、逐 trial 指标、真实接触配置、几何快照、源码/资产/协议原字节快照及 SHA256 清单。离线分析只读取轨迹，不拟合预测器；独立重算命令、原生差异、shield 分母和完整预算。
4. 写逐 seed 正负结果和门判定，随后在另一份协议中定义身体学习与闭环比较。所有更新、模型选择和任务目标先公开冻结，不能把此探针归档直接写成已经验证学习优势。
