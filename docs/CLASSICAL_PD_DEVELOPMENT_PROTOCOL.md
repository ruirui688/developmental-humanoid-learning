# C3 第一批：有限 PD 开发网格

> 2026-10-11；正式运行前冻结。仅 CPU，调优经典反馈基线，计入全部开发交互。

## 1. 研究问题与使用边界

E1 v2 的固定 Kp=4、Kd=0.2 较差，不能视为强经典基线。本批在有限开发网格内选择 PD，检验较差成绩是否仅来自既定增益。它不更新身体模型，也不证明新身体学习方法的优势；增益选择本身属于额外控制器开发。

本批只运行开发 seed **0/1/2**，条件为 **supine / joint 0 / left_shoulder**。它们与历史 E1 开发初态一致，原固定 PD 可以作为精确复现锚点。历史 seed 10/11/12 已使用，不再当作未见最终测试。

新最终留出预留 **20/21/22**，本批不运行它们。C2/C3 方案冻结后再一次执行完整公平评估；不能根据这三个留出追加增益、PID、模型结构或校准。

## 2. 固定候选与目标

```text
Kp = [4, 16, 64]
Kd = [0, 0.2, 1]
候选顺序：Kp 外层、Kd 内层，共 9 对
u = clip(Kp*(target-q) - Kd*v, -0.5, 0.5) N·m
```

q/v 为调用前原生 encoder，target 为已公开当前任务目标。无积分、前馈、接触教师或模型输入；候选在每个 trial 内固定，不从轨迹改变增益。

环境、身体、baseline 接触、限位屏蔽与停止阈值保持 E1。每个候选独立 reset，用原派生 reset seed；100 步/2 s 零力矩前缀计账，前缀末用 encoder 与公开限位选方向一次。控制前 100 步为 `qref+s*0.04`，后 100 步为 `qref+s*0.08`，不得提前知道切换。目标须距公开限位至少 0.03 rad，不满足则记录不可行、不裁剪。

控制权限统一 0.5 N·m；较高 Kp 可能更频繁饱和，必须公开实际努力、速度、动能和接触风险。控制器不能覆盖环境保护。

## 3. 预算、选择与失败

3 seed × 9 候选 ×（100 前缀 + 200 控制）= **27 trials、8,100 控制调用、81,000 物理子步**；其中前缀 2,700 / 27,000，控制 5,400 / 54,000。模拟时间 162 s，身体模型/策略参数更新均为 0。选择开销、所有候选与失败计入开发总账，不只计最佳候选。

选择规则在本批结果前固定：

1. 候选必须三个 seed 都完整，200 个控制转移、无停止/异常/非法请求/非有限；缺失候选不可排序为成功。
2. 最小化三个 **原始完整 tracking RMSE 的均值**，不按最后一点误差或 seed 子集选择。
3. 精确相同均值时，以请求平方力矩积分的三 seed 均值、Kp、Kd、候选编号依次决胜。
4. 无完整候选则记录选择失败。不得补跑到成功或临时扩大网格。

PID 不在本批内。若未来开发证据支持积分需求，另写开发协议、候选与预算；不能在看过新正式留出后追加 PID 并继续宣称未见评价。
