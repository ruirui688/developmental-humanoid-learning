# 接触柔顺性与固定零力矩前缀：无训练对照协议

> 2026-10-10；正式矩阵采集前冻结。仅 CPU，模型、策略和门控参数更新为 0。

前两轮发现被动落地/滚倒与控制终点漏峰。此次检验两个工程条件：较长的地面接触求解时间常数是否改变冲击和穿透；先执行固定零力矩前缀，是否能让后续探索产生更清楚的原生感觉差异。环境柔顺性不是学到的能力，固定等待也不是已经学会稳定或翻身。

## 条件、先验与预算

| 因子 | 冻结条件 |
|---|---|
| 身体与初态 | 同一自建 7.26 kg 身体、8 关节、四躺姿；根 seed 0/1/2，初态与动作随机流独立且跨组共享 |
| baseline 接触 | 资产原值：所有 geom `solref = [0.01, 1]`，不覆盖资产参数 |
| compliant 接触 | 只改 floor 的 `solref[0] = 0.05 s` 与 `priority = 1`；地面接触采用 floor 参数。阻尼比、`solimp`、摩擦与身体自碰撞参数保持原值 |
| 固定前缀 | 0 或 100 控制步（0 或 2 s），期间零力矩、不调用探索器或消费其随机流；无自动稳定检测、状态重置或裁剪 |
| 动作组 | 全程零力矩；前缀后独立关节平滑随机探索，滤波 0.9、力矩上限 0.5 N·m |
| 总时长 | 每组最多 250 控制步、每步 10 个 2 ms 子步：5 s。探索时段分别为 250 或 150 控制步 |
| 停止与信息 | 原停止阈值、限位屏蔽与原生观测不变；接触和世界状态只用于特权诊断 |

`solref` 的正值第一项是 MuJoCo 接触约束求解时间常数，第二项是阻尼比；此处不是测得的软垫刚度。当前 floor 与其他 geom 的摩擦、`solimp` 和第二项相同，优先级选择用于明确地面接触使用哪套参数。逐组保存实际接触配置，并检验实际地面 contact 的 `solref`；身体自碰撞仍采用原值。所有参数都是开发条件，不是生物或硬件安全阈值。

完整矩阵为 **2 接触 × 2 前缀 × 4 姿态 × 3 seed × 2 动作组 = 96 次**。顺序为姿态、seed、接触、前缀、动作组。最大 **24,000 控制步、240,000 物理子步、480 s 仿真时间**；其中前缀 4,800 控制步、48,000 子步，探索时段 19,200 控制步、192,000 子步（均包含零力矩对照）。实际执行与停止前的部分子步分别计账；失败保留，不补跑成功种子。

分别保存包装器已完成的 `control_steps` 和 `control_calls_attempted`，后者包含在子步中途抛错的调用；两种控制计数均按前缀/探索阶段分账。失败时以调用尝试数和实际物理子步核对额外成本，不把尚未返回的部分调用漏掉或填成完整 10 子步。

零力矩的两个前缀标签没有改变实际动作，属于重复的动力学对照，不能当作新增独立 seed。相同总预算下，2 s 前缀牺牲了 100 次探索命令，不能只展示后段而省略前缀成本。此次新预算与此前三次采集的 14,750/147,500 步累计披露；测试预算与正式采集分开记录。

## 记录与事先规定的比较

1. 验证 baseline、零前缀的 24 次状态、原生观测及命令与上一轮逐行精确相等。若偏离，先报告复现失败；不把变动曲线称为仅改变其他因子的结果。
2. 逐组报告全时域 2 ms 地面法向力采样峰值、动能峰值、最小接触距离及法向力积分。积分包含持续承重，2 ms 采样不是连续时间上界；降低峰值但增加穿透也应报告。
3. 前缀末端报告动能、关节速度与原生陀螺仪；零前缀使用初始观测与初始静止状态。不事后设“稳定成功”阈值，不保证 2 s 足以稳定所有姿态。
4. 探索时段逐关节计量请求/实际子步力矩 RMS、力矩时间积分、非零请求被屏蔽的比例、关节增量 RMS。按控制端点的地面接触数量分组作描述，不把接触数量当成已识别的接触位置或因果模式。
5. 在同接触、前缀、姿态、seed 内，将探索与零力矩的原生关节轨迹配对。主要比较各组**前 150 次探索时段命令**的轨迹差异 RMS 和实际力矩 RMS，固定相同命令数量；另报告完整探索时段与总预算。
6. 不同前缀的探索开始状态自然不同，不称为单纯算法提升。跨接触条件的差异归环境；配对轨迹差异只是该固定动作干预的物理响应，不证明可辨识性、预测精度、低风险学习或技能获得。

所有 seed、逐关节数据、早停、非有限标记及例外均保存。没有拟合预测器、回归/在线辨识、奖励优化、教师调用、能力晋级或参数选择。当前只比较这两套固定接触条件，不搜索最佳柔顺性。
