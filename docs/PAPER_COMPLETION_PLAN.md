# 论文完善与多媒体证据计划

## 当前可写入内容

二维概念验证已经具备共同交互预算、多 seed、逐 seed 原始指标、统计检验、训练跌倒图和同步对照视频，可以作为当前论文的主要性能结果。G1 当前新增的冻结测试只能作为软件工程里程碑：它证明 model 4260 在固定动力学、轻初速度扰动和有限 horizon 下通过了预先冻结的测试协议，但尚不能证明发育方法比 Direct PPO 更省样本或更鲁棒。

本轮补齐了三类可审计素材：冻结多 seed/长 horizon 总览图、零注入站立时间序列与 GIF、轻初速度扰动单轨迹恢复时间序列与视频。素材到 checkpoint、源码、上游 revision、seed、条件和 SHA256 的绑定见 `results/validation/g1_multimedia_manifest_20260826.json`。

## 图表和视频规范

1. 主结果曲线显示全部 seeds 的淡色轨迹，同时显示中位数和置信区间；不要只画最优 seed。
2. 所有成功率同时给出分子/分母、horizon 和置信区间；“100%”只能解释为该有限测试集上未观察到失败。
3. 视频角落应烧录方法、seed、checkpoint、仿真时间和测试条件；扰动视频同时显示扰动发生时刻与幅值。
4. 对照视频必须同步仿真时间、相同摄像机、相同扰动和相同终止处理；失败后画面继续保留，不能剪掉跌倒。
5. 最坏 seed、典型 seed 和失败轨迹都应进入补充材料。视频用于解释状态演化，量化结论必须来自原始状态日志。

## 建议的论文叙事

近期论文问题应限定为“能力门控成熟机制能否在达到相同站起/站立成功率时，减少交互、严重跌倒和高风险动作，并改善冻结扰动集上的适应性”。婴儿学习是机制灵感，不是实验结论；计算量允许充分重复练习，但公平比较必须按每组实际 environment steps、GPU 时间、先验样本和教师调用分别计账。

在 P0 对照完成前，G1 图和视频应放在“工程验证/补充材料”，摘要仍只报告二维概念验证。一旦共同预算多 seed 对照完成，再把 G1 学习曲线、风险 Pareto 图和冻结鲁棒性热图提升为正文主结果。
