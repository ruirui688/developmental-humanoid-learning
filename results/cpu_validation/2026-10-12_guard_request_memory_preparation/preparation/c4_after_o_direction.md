## 单个决定：检验 K 加一段已知过去 request

支持一次预算固定的结构检验，采用 K 现有原始尺度模型为骨架，只增加上一合法已知
request 的两个受控轴通道：

```text
phi_P(t) = concatenate(phi_K(t), u_requested_active2(t−1))
```

保持其余 K 输入、目标、位置更新和 22 个输出、原始尺度及固定 ridge λ=0.01 配方；不叠加
N 的 RMS 缩放，不搜索 lag/幅度/权重，不恢复旧位置—速度候选。所加通道由当前双关节
任务定义预先选定，不按相关性从 8 轴中筛选。其他六轴固定零请求不能作为新 RMS 归一
通道制造无意义维度。

这个候选的有限依据是：上一已知请求可在相同当前请求下区分 release 与持续零、onset
与 hold，并且可从本系统已经发出的控制请求维护，不需要特权动力学或新传感器。它是
一个有明确信息来源的有限响应记忆假设。O 的阶段差足以使它成为值得一次检验的候选，
不足以使它成为已被识别的原因或必然改善方案。

必须披露两个限制：一段 request 不能区分持续 hold 的不同持续时长；在 hold 中它与
当前 request 强共线，增加这段输入也会改变 ridge 的表示与先验。即使候选改善，也只能
归因于这个完整结构修订的收益，不能据此单独证明物理延迟或记忆机制。若要识别这些
机制，应另立后续因果实验；本轮不追加此类泛诊断。

## 冻结与反驳条件

1. 使用与 K 相同的 C400 拟合记录 ID、标签及原预算。每一行的过去 request 必须与当前
   输入采用同一定义（包含相同原生 veto 语义）、来自同 trial 的紧邻已发生端点。不得
   读取未来实际力矩、guard投影或模型 W 推断 request。若全部合法前序请求不能恢复，
   冻结前就报告此方案不可实施；不补零、跨 trial、额外采样或悄悄更换拟合人口。
2. 真实在线每步只保存上一实际已发出的已知 request；预测递推只按候选请求序列确定性
   移位该记忆。离线仍用与旧模型相同的保存请求条件，继续披露 oracle 条件；不能把
   预测中的 request 当作真实未来已执行输入。
3. 源码、协议、seed、标签 ID、费用与 P−K/P−D 原完整门先冻结，干净提交首次执行一次。
   H1 hold/release 只作预先指定描述；不能取代完整共同门或成为更宽松的新成功标准。
4. 若不能同时回应一步速度和递推有效域、或原完整门失败，就拒绝此候选进入新控制。
   不追加第二个 lag、不扫描正则、不挑受益类别补跑。公开失败并作一次下一研究决定。
5. 即使已见开发 bank 通过，也只能说明值得冻结新的留出/完整控制实验；仍需新的首次
   C4 完整验证及强 PD 对照，不能释放 C5 或宣布控制收益、安全或发育技能获得。

这个决定收敛为一个具体结构实验，不再开展新的宽泛误差诊断。O 已结束其问题定位职责；
C4 仍是最早未验收阶段，持续目标保持 active。
