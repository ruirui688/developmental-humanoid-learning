# C4 N 独立解释与单一下一方向

本 review 只使用 N 已保存的 metrics/groups/gate/cost 摘要和 run 记录。不读取实际参数或 trace，不调用模型、不重新计算统计量、不重评旧门、不拟合、不执行物理。本文件属于父任务的独立建议，不能使 C4 或持续目标变为已完成。

## 已有结果能说明什么

N 对 K22、D11 的两个冻结门均失败；全部固定 origin 有限且完整。N 相对 K22 的保存均值为：H1 肩速度改善值 -0.0975390076668834，肘速度 +0.052336051958334004；H15 肩/肘位置 +0.13023300859931175 / +0.125974535904474，而速度 -0.04137911444514272 / -0.024519237617876177。H2 位置还有 seed1 的两轴退化。因此，较长跨度位置的改善不能替代一步速度或完整共同门。

H1 肩速度在三个 seed 都退化，N/K RMSE 分别是 0.06088526880942099/0.05561096644994734、0.060927354096870764/0.05573166174768638、0.06144108102165952/0.05562558038194071。这已经否定“问题只来自较长跨度的位置积分”的单一解释。肘的 H1 改善也不能抵消肩的共同验收缺口。

N 首次正式费用保留为 3 次 fit 返回、26,400 scalar label 请求/返回、3 次共同 29×29/22 RHS solve、1,914 个拟合系数、66 heads，以及 N/K 各 6,204 transition 返回；没有新增物理、RLS 或 MPC。RMS 缩放改变正则先验，当前结果只说明这一固定修订没有足够的共同泛化收益。它不证明所有缩放无效，更不支持继续用已见样本选择 lambda 或最佳尺度。

M 的训练投影、floor/shrink 和能量记录描述拟合几何。它们没有识别留出误差的物理原因。N 也没有区分线性类别不足、合法历史不足、传感器/观测问题和未观测动力学；不能把“预测仍不好”改写为“隐藏动力学已证实”。

## 单一下一方向：一次固定的保存误差分解

同意一次、有限的缓存误差诊断；完成后形成一次结构修订的主假设，不继续泛诊断或参数扫描。唯一问题是：同一真实端点上的误差有多少来自局部一步映射，又有多少来自递推状态/历史作为输入后的预测变化？采用父任务选定的 O 同端点 e=b+r 定义，不累加 H1，也不将此定义当作时间传播的独立因果分解。

在新的冻结诊断协议中，只用已有 N/K/D 预测记录，对每个 seed、trial、共同 origin、保存 path step k、轴及信号分别处理。约定全部保存误差是 actual−predicted：

\[
e_{t,k}=x_{t+k}^{actual}-\hat x_{t+k|t}^{recursive},\qquad
b_{t,k}=x_{t+k}^{actual}-\hat x_{t+k|t+k-1}^{one\ step},\qquad
r_{t,k}=e_{t,k}-b_{t,k}.
\]

一步预测须以各自真实当前状态及合法真实过去端点为起点，并且与 recursive path step 的真实端点严格一致。H1 与 H15 的原始 origin 人口不同（100 与 86），不能把各自总体 RMSE 相减来充当此分解。O 采用共同 86 origins、k=1..15，完整 H1 100 只进入已冻结的命令类别描述；不可混用两个人口。先冻结配对、计数和缺失处理；如果缓存缺失，不恢复模型填补、不重新 rollout。D 的绝对 q 必须由保存 H1 terminal_qv 和原 actual−pred error 在同坐标恢复，不能以 qref 估计。

分别保存 signed mean、b/r/e 的平方能量和交叉项，逐 seed、逐轴、逐 q/v 完整报告；不混合位置和速度单位。恒等式是

\[
\|e\|^2=\|b\|^2+\|r\|^2+2\langle b,r\rangle.
\]

不得假定正交或把 r 的平方称为独立解释率；b 和 r 可以相互抵消。此代数分解不是部署时可得到真实未来状态的控制器，也不是纯粹的物理因果归因。r 是同端点局部预测与 recursive 预测之差，包含预测状态、历史反馈及相应非线性/观测传播，不能独自证明遗漏某个传感器。已有多步预测还条件于保存的未来请求，其中含 q/v veto；不能解释为在线控制拥有未来动作信息。guard 投影字段没有保存，必须报告 unavailable，不能从请求或 veto 猜测补出。

冻结报告只回答上述问题，并记录新 reductions、标签/预测记录复用、读取及计算费用。禁止按结果扩增 sign/zero、接触或相关性桶，禁止重拟合、挑选相关性最高的特征、修改旧门或追加物理。三个 seed 和所有有效/缺失窗口均保留。该诊断没有方法通过门，N/K/D 原科学门仍为失败。

## 对一次结构修订的约束

已知 H1 肩速度三 seed 退化，修订至少必须把局部速度映射及其递推一致性作为主要目标；仅改位置积分或再缩放不足以回应已有反证。如果共同端点显示 b 较大且同号偏差稳定，下一修订优先针对一步速度增量表示；如果 r 在保留交叉项后仍带来一致的附加恶化，下一修订优先针对递推状态/合法历史闭合。不能将这两种描述直接命名为已识别的物理机制，也不能把两者无阈值的事后大小比较升级为科学门。

无论结果如何，下一候选须只选一个预先说明的结构变化、相同标签预算和原信息权限，并保留强 PD/固定模型及完整控制优先门。仍须新的冻结留出/首次控制验证才能推进 C4。不能因为缓存诊断看起来合理就把候选放入控制，或把同一 bank 的拟合/排名当作泛化。

本 review 不建议现在猜测并加入更多 IMU 历史、特权动力学、未来实际力矩或任务教师。它建议用一次固定分解把修订对象收敛到局部映射或递推闭合，随后直接形成可证伪的结构实验，而非继续零散审计。
