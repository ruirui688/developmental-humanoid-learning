# C4 原生感觉与局部状态的有限静态审查

日期：2026-10-11。用途：I 过去原 base 残差检验之后的前瞻参考，不是候选采用、实验协议或科学验收。I 必须先行；本审查没有实施新模块。

## 结论

当前环境确实已有 IMU 通道，但它们是 MuJoCo 中躯干 site 的**理想化 gyro/accelerometer 仿真读数**，不是实际机器人 IMU 采集或硬件传感器验证。原生 observation 同时输出八关节位置/速度、执行器力矩反馈和上一请求。它没有姿态/重力方向、根部位置、根部完整速度或接触标签。

目前 lag11 模型只接收两关节 q/v、当前已知 request 与上一连续原生 v；它没有消费已有 IMU、其余六关节或实际过去力矩反馈。这组局部输入一般不能唯一描述自由根部、有地面/身体接触的全部局部动力学。两个连续速度端点能描述近期趋势，但不使隐含根部状态与接触模式自动成为可观测状态。

这支持“输入可能欠充分”这一待检验结构假设，**不证明它是 G 失败的原因，也不证明添加 IMU 会有效**。有限模型阶数、局部线性形式、校准有效域及请求到实际作用的近似等也可造成预测失配。H 的严重低估不足以单独区分这些原因。F 的 IMU/全八关节相关诊断不能用于挑选最佳轴、特征或阈值，也不提供新模块的因果采用依据。

## 源码证据和边界

- `environment.py:196–205`：`observation()` 公开 `joint_position`、`joint_velocity`、`imu_gyro`、`imu_acceleration`、`actuator_torque`、`previous_command`；前两项均为完整八关节。
- `ground_body.xml:15,18,65–68`：根部是 `freejoint`；IMU site 在躯干 `(0,0,.18)`；只有 gyro 与 accelerometer 两种传感器，没有 orientation/frame quaternion 传感器。
- `environment.py:207` 起：根部位置、quaternion、COM、接触与能量均在 `diagnostics()`，不属于原生 observation。把其中 root quaternion 改名为 IMU orientation 并传给部署模型，会改变信息边界。
- `guard_lag_pair_model.py:23–29,93–113`：特征仅两轴当前 v、相对 q、已知起点角度 guard 投影的请求、hinge、常数及两轴 `v-previous_v`。`local_pair_model.py:21` 起 `_pair` 强制长度为二。
- `guard_lag_pair_model.py:3–9,140–161`：历史必须来自同 trial 连续 20 ms 端点，不能补零或跨 reset；数学 rollout 使用各自预测端点推进历史。
- `guard_lag_pair_mpc.py:77–90,119`：rollout 只推进预测 q/v/history。现在没有任何 IMU 状态的预测接口。若未来增加 IMU 特征，不能将实测当前 IMU 复制到所有未来时刻后宣称仍具有正确 H15 闭合状态模型。
- `environment.py:281` 起：真实执行会逐子步实施限位保护；起点 request 不等于未来实际作用历史。当前 `actuator_torque` 可作为过去已观测反馈，但 `t+1` 的实际力矩不能进入 `t` 时刻预测输入。

相同肩/肘 q/v 与最近速度增量，可对应不同躯干转动、重力相对方向、其余肢体构形与接触模式。它们可产生不同下一速度。gyro/accelerometer 提供部分躯干运动信息，仍不直接提供所有接触状态或绝对高度；IMU site 的加速度也不能直接解释为纯重力方向，需考虑身体运动、转动和接触贡献。本审查没有运行传感器轴、符号或重力响应检查。

## I 失败后可证伪的两个候选

### 候选 A：完整原生 IMU 块的一步增量预测消融

结构假设：只用局部编码器历史遗漏的躯干运动，能够由决策时已到达的六维 gyro/acceleration 部分解释，并改善未见轨迹的**下一完整 20 ms 端点**预测。依据是自由根部动力学与传感器信息类型，不是 F 的最强相关轴。

最小实现应保持冻结原 base 不变，仅为其下一 v 预测增加零初始化的小线性残差头，输入固定为完整六通道当前 IMU；单位尺度、初值、正则与学习配方在新数据前一次冻结。若只允许过去滤波，应固定滤波器与初始化并记录其状态，不能以全试验均值归一化、读未来样本或事后删冲击点。零初始化头提供学习前表现和同信息零修正对照。

所需证据：同一付费物理轨迹上的 frozen base、I 残差候选与 IMU 候选作配对一步预测；完整/partial、切换段、每 seed、最坏速度误差和停止附近误差分别公开。旧 G/H 已揭晓数据只能开发，不能称新留出。采用前须冻结新留出 seed/轨迹与改善门；若只改善平均误差却继续严重低估边界，或仅开发 seed 有效，应否定采用。此门仅评价信息的预测增量，不能直接宣布控制改善。

数据充分性：首先通过采集源码确认存储的原生 IMU 是该控制起点的数据、时间对应且覆盖完整六通道。若已有保存数据足够，可先做零新物理的开发检验；读数不存在、缺失或只有诊断真值时不能补造。预测控制部署另需满足未来状态闭合：要么单独冻结可预测的观察器状态，要么明确改成一步反馈控制并重新比较；不把当前 IMU 恒定复制为未来真值。

### 候选 B：从 IMU 历史得到因果重力方向代理

结构假设：raw IMU 对快慢根部运动的混合过强，而 gyro 积分与受限加速度校正形成的三维重力方向代理，能提供更稳定的重力方向信息。它只有在 A 暴露的必要信息/初始化问题支持时才值得开发，不与 I 同时堆叠实施。

该代理只能消费过去/当前 gyro 和 acceleration。加速度在运动和接触时可能不能与重力分离，尤其躺姿接触冲击期间；静态校正的可信条件、初始化未知状态、失效标志与恢复行为必须预先冻结。不得用 root quaternion 初始化、修正或选择滤波器。若需要近静止初始化，所有方法共享同一付费前缀及实际初始条件，不能加隐藏支撑/未计账 settling。没有可信初始化时应保留 unknown，不能补出“真实 orientation”。

所需证据：与 A 使用相同信息、物理轨迹和学习预算，比较 raw IMU 与因果代理的预测增量；根部 quaternion 至多用于独立离线误差诊断，不能影响滤波状态、样本筛选、超参或控制。完整模型仍需证明在匹配控制中能预测自己的代理/潜在状态；代理漂移、运动加速度误校正或留出失效均为可公开的否定结果。它仍不保证接触模式充分可观测。

## 可采用的有限预算建议

以下为上限建议，尚未登记为实际实验协议或实际费用。若现有开发数据已含可用原生 IMU，先限定一次保存数据的一步检验，新增物理/在线更新均为零；离线残差拟合、滤波状态更新、预测调用与读取费用分别计账。

若确需新数据，可将两候选及各对照共享一次开发采集与一次新留出采集：三个开发 seed 各 100 前缀 + 300 完整辨识步；三个新留出 seed 各 100 前缀 + 200 评估步，总上限 2,100 控制调用 /21,000 子步。单个两输出残差头只在 900 开发转移学习，上限 1,800 scalar 更新；两个候选的拟合费分别记录，不能因共享物理就合并或忽略计算。使用新的 seed bank，且从初始状态到停止的全部付费调用计入预算。

发生停止即保留并结束该 trial，不补跑至成功、不把短轨迹当效率优势、不使用部分 RMSE 排名。预测门失败就公开负结论，暂停该候选采用；通过后再单独冻结匹配控制、完整优先门与独立交互预算，C4 旧门保持失败。这里没有给额外物理控制授权或预判两个候选会通过。
