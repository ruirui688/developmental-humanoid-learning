# L 固定数据增量方案静态审查

结论：未发现概念上的实施阻碍。可以在配方、输入来源、预算及比较门冻结后推进这一次离线开发。该方案尚无执行结果，本审查没有读取实验 payload、拟合模型、运行检查或新增物理交互。

## 被审查的固定方案

保持 K 的 x22、phi29、先验和绝对 ridge 强度不变；每 seed 使用 C sparse 校准 400 transitions，加上已有 G PDselected 完整控制 200 transitions，共 600。三次求解学习 22 个原生下一状态输出，评分只使用已有 C common prediction 100，报告 H1/H2/H5/H15。K learned22 和 D11 均冻结，不重拟合；G PD 训练行不得同时作为评估比较。无新增物理、维度或参数搜索。

## 执行前必须冻结的解释与实现边界

1. **披露数据的任务能力。** G PD 轨迹来自已有任务能力的经典控制器，并有目标相关的状态和动作选择。虽然输出监督仅为原生状态转移，且未使用预训练策略或外部动作教师，这仍不是没有任务先验的冷启动纯发育证据。PD 增益开发费用和采样能力须保留披露。
2. **把结论限定为固定数据增量。** 400→600 同时改变样本数、轨迹分布、经验权重和不变绝对 ridge 先验的相对影响；因此不能把结果归因为覆盖范围单一因素，也不能据此唯一识别 K 失败原因。建议正式名称使用“固定数据增量开发”。
3. **保留比较的不对称性。** L 使用更多已付费转移，K/D11 为冻结历史基线，不能据此宣称等预算算法优势或样本效率。C common prediction 已见，仅是开发评分；此前 K/D 的失败门不追认，不释放 C4/C5 科学门。
4. **绑定来源与连续性。** 固定两套来源的清单、哈希、动力学和配置版本，明确 seed 映射与 8 轴 prefix qref。每条训练样本具有完整原生 before/after 和两次连续过去端点；不得跨 trial、reset、partial 或 stop 拼接 previous_v，也不得补零。训练仅限 C 校准及 G PD 完整控制，不能混入 C prediction 或 G learned/cold。
5. **维持输入与标签权限。** 输入仅当前原生状态、合法连续历史与已知请求；实际下一原生状态仅作标签。PD 目标、未限幅 PD 力矩、奖励、跟踪误差或控制动作不能成为额外输入/监督目标；接触、root、隐藏动力学和未来实际施加力矩不得进入模型。多步仍递推全部 22 通道，不复制当前 IMU 为未来 IMU。
6. **先定比较门。** 在执行前分别写明 L 相对冻结 K 的增量门与相对 D11 的原有门，以及每个轴/seed/时距和完整计数要求。不得看到结果后选择更有利的基线、分量或时距。C 多步只可解释为“条件于已记录请求序列”的预测；包含 q/v veto 的未来请求序列不能充当因果规划或闭环控制成功证据。
7. **完整计账。** 本次重复使用 C 的 26,400 scalar labels，加 G PD 的 13,200，共 39,600；三次求解、1,914 个拟合系数，零新增物理。原始交互及历史 PD 选择成本仍在累计账本，不因数据复用归零。

PD 反馈会使 q/v 与请求相关；ridge 可求解不等于有充分激励或能识别动力学。该固定数据增量假设合理但结果未定。当前不建议追加模型、参数或实验；先完成冻结方案的一次开发，完整保留正负结果。
