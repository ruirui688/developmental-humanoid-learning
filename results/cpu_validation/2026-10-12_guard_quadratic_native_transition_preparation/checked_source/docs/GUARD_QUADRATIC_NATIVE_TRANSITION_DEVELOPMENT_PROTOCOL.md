# C4 Q：固定局部二阶原生转移开发协议

P单段请求记忆相对K/D均未过开发门，H1v约3%改善伴H2/5/15退化。本次直接检验
一个不同函数类的有限候选，不再做保存数据诊断、不追加lag或扫描lambda。
它是局部二阶近似的建模假设，不能从旧负结果断言已经识别了非线性、摩擦或接触原因。

## 唯一配方

以K原始phi29、x22与原prior为基底，只追加六个当前变量的全部21个二次单项：

```text
z = ((q0-qref0)/.12, (q1-qref1)/.12, v0/1, v1/1, startG0/.5, startG1/.5)
quadratic21 = (z[i]*z[j] for i=0..5 for j=i..5)
phi50 = concatenate(phi29_K, quadratic21)
W50x22 = solve(Phi50.T @ Phi50 + .01*I50, Phi50.T @ saved_K_Delta400x22)
```

两个q值是原phi29中的相对位置；v与startG也直接来自原phi29。尺度来自已经公开的
StudyAbort位置.12rad、速度1rad/s和最终权限.5Nm，不读训练或评估来选择尺度。
原29列完全不动。零二次列保留，仍计入50列；不删除、补数据、改尺度或添加floor。
没有RMS估计、中心化、特征筛选、P过去请求、N输入尺度或第二配方。

构型、速度与动作耦合给局部二阶近似以动机，但实际刚体动力学、接触与摩擦未必
属于这个函数类。新增尺度也改变相对正则先验；实验检验整个固定配方，不能归因为
某个单项的因果作用。有限样本方差、弱激励与递推发散是需要保留的失败可能。
这是公开建模先验，没有预训练任务策略、动作教师或隐藏动力学参数。

## 数据、闭合与信息权限

仅使用原C sparse400的K保存Phi400x29、Delta400x22、训练IDs和qref，每seed一次fit。
K只恢复原weights，不重拟合；D只恢复原sparse11 snapshot，不更新。
N纯来源支持与K纯原生/guard/指标函数沿用精确pins；原C/D/K九输入hash及来源commit
保持P/N同一冻结身份。首次执行前核完整clean exact HEAD与全部源码committed bytes。
不读取L/G数据、旧预测、实际力矩、接触、root姿态、隐藏参数或旧更新日志。

训练21列仅由已保存K设计生成，不重生标签。新训练标签用途26,400scalar与历史费用
分列。C原trace仍完整读取/解压/解析计费，只保留同prediction trial合法原生窗口，
其余字段立即丢弃。C原calibration原生端点不为Q生成新标签或挑选特征。

预测中current guard/hinge/prior全沿用K，在预测自己的当前状态上重算phi29与21项。
22输出全部自身闭合递推；previous_v每步推进旧current v，不读未来真实感觉。
保持原prior的位置规则，新增列prior系数为0。禁止投影预测到真实未来状态、裁掉
非有限轨迹或靠未来实际力矩修正。非有限或缺失保留失败，不补跑。
P的过去请求结构不迁移到Q。

576通道组。共享原目标条件、保存未来请求序列、权限与完整分母；该未来请求是

H2/H5 q/v及H15v各seed不劣。H1q仅描述。零/非有限基线、缺组或部分轨迹使相应门
失败/不可评估，不排名停止子集。双门均通过才考虑新留出与matched完整控制。
无论开发结果，scientific_adoption、C4验收及C5依赖解除都为false；不追认旧门。

0新增物理、RLS、MPC，不解释为0计算或等总预算。

保存parameters.json、predictions.jsonl、metrics.json、run.json、manifest.json；
参数包括feature顺序/公共尺度、Phi50/Delta/Gram/cross/normal/weights、原训练IDs、
qref、全部基线指纹。费用在尝试前登记，返回/失败和partial paid分别保存。

不把非有限改成0。计时排除最终序列化/写盘；准确第一次stdout/stderr与源码保留。

partial。已验证的P失败JSON合同只复用，不重跑旧case或旧数学。所有合成计算单列，
准备不读取真实参数/trace。代码与协议、准备检查先冻结提交并推送，再从clean提交
首次正式执行一次；已有目录拒绝覆盖。开发失败不进控制、不自动扩阶/加数据或扫参。
