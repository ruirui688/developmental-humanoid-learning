## 3. 分支与解析 Jacobian

原九列次序不变：`[v0,v1,q0-qref0,q1-qref1,G0,G1,h(G0),h(G1),1]`，`h(G)=sign(G)*max(abs(G)-.25,0)`。q/v 固定为记录原生端点；`G` 是当前 q 下的公开 ±.5 Nm clip 与 .03 rad angle guard，不是下一间隔实际力矩。

沿用原每轴四个闭区间：`[-.5,-.25]`、`[-.25,0]`、`[0,.25]`、`[.25,.5]`，两轴笛卡尔积共 16 盒。每条 H1 记录检查全部 16 盒成员关系，但只对**包含原 logged request 的盒**建 J；每轴最多两个相邻盒，因此每记录最多四盒。切点保留所有合法单侧身份与方向，不合并相同 J，不挑最有利侧；±.5 外的 clip 分支没有合法权限，不添加到人口。angle guard 在固定 q 上使用原 `<= / >=` 规则，u=0 两侧分别保留。

在每个保留盒内：

`J_ij = (theta[i,4+j] + theta[i,6+j]*h'_j) * G'_j`。

阻断方向 `G'=0`，未阻断且在权限内 `G'=1`；内侧 hinge 区间 `h'=0`，外侧区间 `h'=1`。不差分调用 `model.predict`，不做额外 rollout，也不在远处盒重新求根。

对 2×2 J 进行 SVD，沿用 `s > 128*float64_eps*smax` 的 rank 规则，零矩阵 rank 0。不扫描经验 rank 容差。计算唯一 Moore–Penrose 最小范数映射：

`delta_u = -J_pinv * e`，`mapped_error = -J*delta_u`，`unmapped_error = e + J*delta_u`。

保留 singular values、rank、两个误差向量、各轴 delta、原请求到四盒边界/权限边界的余量、`u+delta_u` 与方向/区间关系。若需要数值像空间兼容标记，只采用共同两 head 的继承浮点规则：`tol=128*eps*max(1,sum_i abs(e_i)+sum_ij abs(J_ij*delta_u_j))`；报告原残差值与 tol，不能将此数值标记升级为科学阈值。

原权限与分支关系按原闭区间严格检查，不增加边界容差。有限但像空间不兼容、超权限或跨原盒均标记这个局部映射不可评，不 clip，不换分支，不修正 e，不搜索较好的 delta。**rank 1 的最小范数 delta 越界只使该映射不可评，不证明不存在另一个沿 nullspace 的可行解；本项不做该搜索。** rank 0 的 delta=0 也不能把非零未映射误差解释成已经补偿。
